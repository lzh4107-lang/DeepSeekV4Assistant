# DeepSeek V4 Assistant

A Windows and Android DeepSeek V4 client derived from the mature open-source
[Kelivo v1.1.17](https://github.com/Chevey339/kelivo/tree/v1.1.17) codebase.

## Features

- Official `deepseek-v4-flash` and `deepseek-v4-pro` defaults
- Streaming chat, reasoning output, tool calls, and Markdown rendering
- Image, PDF, DOCX, text, and common source-file attachments
- Web search through DuckDuckGo, Bing, SearXNG, Jina, Tavily, and others
- Windows-only Douyin search with persistent WebView2 login and chat handoff
- Local chat history, backup/restore, proxy support, assistants, and themes
- On Windows, app data and temporary files use
  `D:\DeepSeekV4AssistantData` when a fixed D drive is available

The app asks for the user's own DeepSeek API key on first launch. No third-party
API key is bundled or resold.
