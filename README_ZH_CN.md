# DeepSeek V4 助手

一个面向 Windows 和 Android 的 DeepSeek V4 客户端，基于成熟开源项目
[Kelivo v1.1.17](https://github.com/Chevey339/kelivo/tree/v1.1.17) 定向开发。

## 功能

- 默认支持官方 `deepseek-v4-flash` 与 `deepseek-v4-pro`
- 流式对话、思考内容、工具调用与 Markdown 渲染
- 上传图片、PDF、DOCX、文本及常见代码文件
- DuckDuckGo、Bing、SearXNG、Jina、Tavily 等联网搜索服务
- Windows 专属抖音搜索页，可保留登录状态并将当前结果带入对话
- 本地聊天历史、备份恢复、代理、自定义助手和深浅色主题
- Windows 存在固定 D 盘时，将应用数据和临时缓存定向到
  `D:\DeepSeekV4AssistantData`

首次启动会要求输入自己的 DeepSeek API Key。程序本身不提供、转售或内置任何
第三方密钥。

## 平台差异

- Windows：聊天、文件、联网搜索、抖音搜索。
- Android：聊天、文件和联网搜索。抖音搜索页不打包到移动端入口。
